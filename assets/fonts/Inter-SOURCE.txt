Shipped as InterVariable-subset.woff2: the upright variable WOFF2 from the
official v4.1 release source, subset to Latin, Latin Extended-A, punctuation,
arrows and math operators. Both axes (wght, opsz) and the default layout
features are kept. Source file:
https://raw.githubusercontent.com/rsms/inter/v4.1/docs/font-files/InterVariable.woff2

Licensed under SIL Open Font License 1.1; see Inter-LICENSE.txt.
https://raw.githubusercontent.com/rsms/inter/v4.1/LICENSE.txt

Regenerate the subset with fontTools (pip install fonttools brotli):

  pyftsubset InterVariable.woff2 --flavor=woff2 \
    --output-file=InterVariable-subset.woff2 \
    --layout-features+=tnum,case,zero,frac,numr,dnom,sups,subs,ordn \
    --unicodes="U+0000-017F,U+0192,U+0218-021B,U+02BB-02BC,U+02C6-02C7,U+02D8-02DD,U+0300-0304,U+0306-0308,U+030A-030C,U+0326-0328,U+1E9E,U+2000-206F,U+2070-209F,U+20AC,U+20B9,U+2113,U+2116,U+2122,U+2126,U+212E,U+2190-21FF,U+2200-22FF,U+25A0-25FF,U+FEFF,U+FFFD"

Text in a script outside these ranges (Cyrillic, Greek, ...) falls back to the
system font. Add its range and regenerate before publishing such text.
